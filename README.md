# Приглашение на юбилей Юлии

Лёгкий статический одностраничный сайт-приглашение.

## Технологии

- React
- TypeScript
- Tailwind CSS
- Vite

В проекте нет backend, API, базы данных или авторизации. Данные мероприятия находятся непосредственно в `src/App.tsx`.

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации: `npm run build`.
